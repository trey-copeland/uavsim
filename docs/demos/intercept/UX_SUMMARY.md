# UX design summary — intercept demo

Designed a thin, GitHub-Pages-friendly static dashboard under `docs/demos/intercept/` (not the portfolio matrix): sticky header with Success/Fail nominal toggle and KPI chips for P(capture), n trials, and capture radius; primary N–E 2D trajectory (optional N–Up) with target/ownship paths, scrub-synced markers, optional MC 5–95% bands, and a play/scrub transport; range(t) series with 1 m capture line; MC min-range histogram and fixed-NDI/plant-scatter copy; dark research tokens aligned with `docs/showcase/styles.css`. Data contract centers on a single offline `data/demo.json` built from success/fail nominal runs plus `monte_carlo/{trials.csv,summary.json}`, using `intercept_success` for P(capture) and optional precomputed band polylines. Battery UI, full Flight-3D attitude, and trial clouds are out of scope for v1; implementer checklist and acceptance criteria are in `IMPLEMENT_CHECKLIST.md` / `UX_SPEC.md` §8.
